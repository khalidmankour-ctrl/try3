# On-page SEO checklist

Per page:

- [ ] **Title tag** — unique per page, primary keyword near the front,
      ≤ ~60 characters (so it isn't truncated in SERPs). Not just the brand
      name repeated on every page.
- [ ] **Meta description** — unique per page, ≤ ~155 characters, written as
      persuasive ad copy (it's not a ranking factor but drives click-through).
- [ ] **Heading hierarchy** — exactly one `<h1>` per page describing the
      page's topic; `<h2>`/`<h3>` nested logically, not skipped for styling
      reasons.
- [ ] **URL** — short, descriptive, hyphen-separated, lowercase; matches the
      page topic.
- [ ] **Image `alt` text** — describes the image content/function for screen
      readers and image search; decorative images get `alt=""`, not a
      keyword-stuffed description.
- [ ] **Internal links** — descriptive anchor text (not "click here"),
      linking to genuinely related pages; avoid orphaning important pages.
- [ ] **Content depth** — the page actually answers the query it's targeting;
      thin/duplicate content across near-identical pages hurts more than it
      helps.
- [ ] **Above-the-fold clarity** — a visitor (and a crawler) can tell what
      the page is about without scrolling.

## Anti-patterns to avoid

- Keyword stuffing in title, headings, or body text.
- Identical title/meta description copy-pasted across many pages.
- Hidden text or links (visually hidden but present in HTML) used to target
  keywords.
- Doorway pages that exist only to rank, funneling everyone to one real page.
- Auto-generated low-value content at scale.
